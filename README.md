# 南光AIGC - 加载文本插件

> 为 ComfyUI 提供的文本加载节点，支持手动输入提示词或上传本地 `.txt` 文件，方便管理长文本工作流。

## 特性

- ✅ **全中文界面**：节点名称、按钮、标签均为中文
- ✅ **手动编辑**：直接在节点内输入任意文本
- ✅ **上传文件**：点击“选择文本上传”，将本地 `.txt` 文件存入插件专属文本库
- ✅ **文件切换**：通过左右箭头浏览并加载已上传的文本文件
- ✅ **工作流持久化**：文本内容会随工作流保存，下次打开自动恢复
- ✅ **自动处理重名**：上传同名文件会自动重命名（如 `文件名_001.txt`）

## 安装方法

### 1. 下载插件

将本文件夹 `ComfyUI-Nanguang-LoadText` 放入 ComfyUI 的 `custom_nodes` 目录中。
